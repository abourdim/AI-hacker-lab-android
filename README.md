# 🧪 AI Hacker Lab — Android wrapper

Capacitor wrapper that packages the [AI-hacker-lab](https://github.com/abourdim/AI-hacker-lab) web app as an installable **Android APK**.

> مختبر هاكر الذكاء الاصطناعي · AI Hacker Lab

An interactive AI learning lab with four age-tiered workshops — from drag-and-drop sorting for kids to building neural networks with TensorFlow.js for teens. Includes badges, certificates, a parent dashboard, and a learning journal, all running locally on your device.

## Quick start

```bash
./manage.sh    # auto-detects your OS, then opens the menu
```

Build, test on emulator, and prepare a Play Store release from a single guided menu. See [WORKSHOP.html](WORKSHOP.html) for the full step-by-step guide.

## Download the latest APK

[📦 v1.0-debug release](https://github.com/abourdim/AI-hacker-lab-android/releases/latest) · [![QR](releases/download-qr.svg)](https://github.com/abourdim/AI-hacker-lab-android/releases/latest)

Scan the QR with an Android phone, or `adb install -r AI-hacker-lab-v1.0-debug.apk`.

## Capabilities required at runtime

- Internet (cloud assets / model fetch on first launch)
